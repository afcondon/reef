# Conspicillum reference

Generated from `Reef.Conspicillum.Reference`: the parameter catalogue, the rule vocabulary,
the chord table and the presets, as the code has them. Do not edit this file; change the
code and run `node tools/conspicillum-reference.mjs`. The conformance suite compares this
file with what node and the BEAM both print, so it cannot drift from the instrument.

A scene is written as one line, `#`-separated, the way Tidal writes a pattern:

```
s "fd-beat-bar" # walk 0.2 0.1 0.1 # grid 8 # swing 0.62 # fix snare 0.5 (pshift 1.5)
```

Anything a line does not say is Sector's default: sixteen grains a bar, following the tape.
The **term** column below is how a line sets each parameter.

## Parameters

Every number a player can turn. **Neutral** is where a scene that says nothing about it
stands. **Needs** is what has to be engaged for it to be heard at all: an effect's depth
does nothing while its rate is off. Ranges marked *log* turn exponentially, so each step
of the knob is the same ratio.

### The grain

| parameter | term | range | neutral | needs | what it does |
|---|---|---|---|---|---|
| **grain length**<br>`grainLength` | `sustain` | 10 ms – 2.00 s *log* | 125 ms |  | How long each grain sounds. On a tape followed at a sixteenth a grain, a sixteenth is the whole slice; longer grains overlap, shorter ones leave gaps. |

### The read head

| parameter | term | range | neutral | needs | what it does |
|---|---|---|---|---|---|
| **read position**<br>`readPosition` | `position` | 0% – 100% | 0% |  | Where in the material the read head sits, as a fraction of it. With the tape followed, it is an offset from where the tape would be. |
| **spray**<br>`spray` | `spray` | 0% – 100% | 0% |  | How far each grain may land from the read head, at random, as a fraction of the material. |
| **tape follow**<br>`tapeFollow` | `follow` | -1.00× – 2.00× | 1.00× |  | How fast the read head moves along the tape, against the bar: 1 reads the tape in time, 0 holds still, 2 reads a bar of tape in half a bar, negative runs backwards. |

### The walk

| parameter | term | range | neutral | needs | what it does |
|---|---|---|---|---|---|
| **jump**<br>`walkJump` | `walk <jump> _ _` | 0% – 100% | 0% |  | How often the read head relocates to another step in the bar and reads on from there. The walk resets at every bar line. |
| **repeat**<br>`walkHold` | `walk _ <repeat> _` | 0% – 100% | 0% |  | How often the read head stays where it is, so the grain repeats the one before it: Sector's repeat, and a run of them is a stutter. |
| **return**<br>`walkHome` | `walk _ _ <return>` | 0% – 100% | 0% |  | How often a displaced read head goes back to where the tape is. |
| **reach**<br>`walkReach` | `reach` | 0 – 32 | 0 |  | The furthest a jump may go, in steps of the walk's grid; 0 means anywhere in the bar. |

### Swing

| parameter | term | range | neutral | needs | what it does |
|---|---|---|---|---|---|
| **swing**<br>`playSwing` | `swing` | straight – 0.75 | straight |  | Where the offbeat of each pair lands: 0.5 straight, 0.66 triplet, 0.75 dotted. |
| **tape swing**<br>`tapeSwing` | `tapeswing` | straight – 0.75 | straight |  | The swing the tape was played with, so its slices are cut on its own hits. Equal to the swing, a followed tape plays as recorded. |

|---|---|---|---|---|---|

## Rules

A rule picks grains and does one thing to them. Rules are what no hardware granulator can
express, because there a grain has no identity to count.

| which grains | written | |
|---|---|---|
| every *n*-th, from the *k*-th | `every 3 0 (speed -1)` | counts across bars, so every third grain stays every third |
| a chance of each | `sometimesBy 0.2 (ratchet 3)` | seeded: the same scene makes the same choices |
| all of them | `always (send 1)` | |
| the ones that read like a hit | `fix snare 0.5 (pshift 1.5)` | kick, snare or hat, above a score threshold |

The amount can be one number, `"a b c"` for one value per firing, or `"<a b c>"` for one
value per bar, as in Tidal: `fix kick 0.5 (rsnpitch "<36 36 39 31>")` is a bassline played
by the kick drum.

| op | acts on | how |
|---|---|---|
| `speed` | speed | multiplies |
| `gain` | gain | multiplies |
| `length` | grain length | multiplies the grain's length |
| `pan` | pan | sets |
| `accelerate` | glide | sets |
| `shape` | waveshape | sets |
| `crush` | bit crush | sets |
| `coarse` | sample-rate reduction | sets |
| `lpf` | low-pass | sets |
| `hpf` | high-pass | sets |
| `bpf` | band-pass | sets |
| `res` | resonance | sets |
| `vowel` | vowel | sets |
| `pshift` | pitch shift | sets |
| `tremolo` | tremolo | sets |
| `phaser` | phaser | sets |
| `genv` | grain envelope | sets |
| `gtilt` | envelope peak | sets |
| `gplat` | envelope plateau | sets |
| `atk` | attack | sets |
| `hold` | hold | sets |
| `rel` | release | sets |
| `curve` | envelope curve | sets |
| `rsnpitch` | resonator | sets |
| `rsndecay` | resonator decay | sets |
| `rsnbright` | resonator brightness | sets |
| `rsnmix` | resonator mix | sets |
| `rsnmodel` | resonator model | sets |
| `shift` | where the grain reads | moves the read head by a fraction of the source, wrapping; on a followed tape, a jump |
| `ratchet` | how many times it sounds | one grain becomes *n* inside its own slot: the stutter, the roll |
| `send` | where it goes | a copy to send bus 1 (A) or 2 (B), at the bus's level |
